# Ecomm Boilerplate (Next.js + MongoDB + Tailwind)

A reusable e-commerce boilerplate built with Next.js (App Router), MongoDB, and Tailwind CSS.  
This template helps developers quickly start new e-commerce projects without repeating the same setup process each time.

---

## Features

### Core
- Next.js 15 (App Router) + TypeScript
- Tailwind CSS with theme configuration
- Modular folder structure
- Cloudinary for image uploads
- MongoDB + Mongoose models
- Authentication-ready (NextAuth)
- Review and Rating system
- Admin dashboard for product management
- Cart and Checkout foundation
- Easy theming via config file
